# Mechanistic low-digit projection check

This separately specified comparison tests actual finite p-adic digit truncation of the quantized parameter grid, rather than only choosing a p-adically indexed real alphabet. For integer grid value n=round(w/s), return the balanced representative of n modulo p^k, with largest p^k under the code-bit cap. Conversion to the integer grid and modular reduction use FP64; the resulting small code and dequantized real output use FP32. The wider matrix accumulator has no modular wrap. Straight-through gradients, learned scales and clipping factors, minibatches and all128 continuation steps remain identical to the original experiment. A8 stays ordinary INT8; low-bit activation variants also use the p-adic projection. The mixed schedule retains ordinary A4 as specified.

Use bases2/3, W2/A8,W3/A8,W4/A8,W4/A4 and alternating W2/W4 with ordinary A4. Identical physical encoders are exact aliases. Add a full signed INT W4/A4 control to complete the matching alphabet for binary projection. At360M check W4/A8 with both bases. All use seeds17/29/43 and both existing test corpora. Compare with the corresponding clipped codebook as well as the original integer baseline. These are additional mechanistic tests, not changes to or replacements for the initial primary matrix. No outcome-dependent code width, rate, seed or checkpoint selection is allowed.
