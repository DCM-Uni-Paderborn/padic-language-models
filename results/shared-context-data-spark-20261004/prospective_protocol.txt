Group aggregation: for each affected query position, remove the mandatory most recent eight keys from the optional pool. For each query head, rank its optional-key scores using exact twice-midrank `2*(number strictly smaller)+(number equal)-1`. Sum these integer ranks across the three heads. This fixed rank aggregation gives all heads equal influence without comparing differently scaled scores. It is a changed group router, not an identity with the earlier per-head selector or a newly trained p-adic metric. A same-code trie can recover identical per-head depths before aggregation.
